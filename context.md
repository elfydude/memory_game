# Repository Context

## What this project does
This repository contains a browser-based Memory / Concentration card game. The game challenges the player to flip cards and match pairs while tracking moves, time, and performance.

It is implemented as a lightweight front-end app with HTML, CSS, and JavaScript only, so it runs directly in a browser without a backend or external libraries.

### Included features
- 4x4 and 6x6 board sizes
- Card flip animations
- Move counter and timer
- Star rating system
- Best-score persistence using browser local storage
- Keyboard accessibility support
- Responsive layout for desktop and mobile screens
- No external dependencies

## How it is used
The app is opened by loading `memory-game.html` in a browser. Players click or keyboard-navigate through tiles, match all pairs, and try to finish in as few moves as possible.
